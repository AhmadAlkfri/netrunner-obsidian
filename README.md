# Netrunner

A Cyberpunk 2077 inspired theme. Featuring a subtle CRT effect on the text, 
glowing red / yellow / cyan colouring, cyberpunk inspired fonts
and completely reworked buttons, scrollbars, toggles and more. 
Also includes a subtle glitch effect on hover for certian UI elements.

## Fonts

Netrunner is designed around **Rajdhani** (UI and prose) and **JetBrains Mono**
(code and math).

Without them installed the theme falls back to your system sans and monospace.
It's fully usable that way, but the typography is a large part of the look, so
installing both is recommended.

Both fonts are free and licensed under the SIL Open Font License.

### Download

- **Rajdhani** — https://fonts.google.com/specimen/Rajdhani
- **JetBrains Mono** — https://fonts.google.com/specimen/JetBrains+Mono

Click **Get font → Download all** on each. You'll get a zip containing static
`.ttf` files.

Install every weight you find. The theme uses Rajdhani 400/500/600/700 and
JetBrains Mono 400/700.

### After installing

Restart Obsidian completely — reloading the theme is not enough, the font cache
is read at startup.
